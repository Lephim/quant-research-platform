# Results and provenance

`tables/` contains verbatim plain-text extracts of existing notebook outputs. They are historical records, not results recomputed during repository cleanup. Each filename identifies the notebook and zero-based cell index; `docs/research-record.md` gives context.

For future empirical runs, save tables under `tables/` and figures under `figures/`. Accompany each run with universe, source/data checksum, download and adjustment settings, evaluation dates, training windows, rebalance intervals, estimator choices, caps, cost convention, random seed if relevant, dependency versions, and source commit. Keep raw data under the ignored root `data/` directory and follow provider redistribution terms. Do not mix synthetic test output with empirical research tables.
