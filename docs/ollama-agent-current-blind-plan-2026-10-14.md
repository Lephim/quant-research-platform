# Current snapshot-backed agent: prospective held-out check

Frozen before running the post-guard evaluation on 14 October 2026. This is a new set of eight prompts, separate from the original twelve-case blind evaluation. The case file is `src/agent/current_agent_cases.py`; its SHA-256 is recorded in the JSON report and must be checked before interpreting results. Use the existing `qwen3:8b` model and the 2018–2024 multi-asset price snapshot, verified by its manifest SHA-256. Do not revise these cases after observing results.

Five empirical prompts test a covariance pair, a reversed-order training-window pair, a three-value cost sweep, a mean-estimator pair, and a four-arm covariance-by-mean grid. Three prompts test a missing universe, a universe incompatible with the snapshot, and an unsupported transaction cost. Every empirical call must use the same snapshot return object. The optimizer is replaced with canned metrics so this measures agent control and presentation, not portfolio performance.

Primary pass rule per empirical prompt: the successful effective tool calls must match exactly the requested configurations, with no duplicate or extra successful calls; the answer must show exactly the requested number of runs, the snapshot checksum, and no tool error. A missing arm or parameter mismatch fails even if the runner correctly suppresses partial results. Invalid requests pass only if no backtest executes and a helpful response appears. Record failed attempts, errors, latency, and the final answer for every case. Report exact-call success and safe suppression separately; do not treat a suppressed incomplete comparison as a successful experiment.

Run once in the fixed case order with `python -m agent.evaluate_current --snapshot data/snapshots/multi_asset_2018-2024_2026-10-14.csv --output results/tables/ollama_agent_current_blind_2026-10-14.json --model qwen3:8b`. This is a small workflow check, not a population reliability estimate. Transient Ollama errors remain failures in the primary run; any retry must be reported separately without replacing the first result.
